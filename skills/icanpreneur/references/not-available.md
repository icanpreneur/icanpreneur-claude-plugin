# What the tools cannot do

The Icanpreneur website, docs and platform describe features that these tools do not provide. If the user asks for one, say it is not available through the tools, say what you can do instead, and never imply it happened.

| The user asks for                                                                   | What to say and offer                                                                                                                                                                     |
| ----------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Live help during an interview (IVA as co-pilot, follow-up suggestions in real time) | Not available here. Prepare the script now (`icanpreneur-build-research`); after the interview, import the transcript. For an IVA-led interview, create the interview and share its link. |
| A conversation with IVA, or "Work with IVA" in the Canvas                           | Not available here. You can discuss and pressure-test their material in this conversation, using the saved workspace evidence.                                                            |
| Builder guided tasks (for example "Refine Customer Segments and Customer Problems") | Not available as a step-by-step task. Read and edit Canvas items directly, and apply the platform definitions (`references/definitions.md`).                                              |
| Focus Mode (filtering the Canvas by segment)                                        | Not a tool. Read the Canvas and filter in your answer by segment.                                                                                                                         |
| Finding a business idea from their skills and interests                             | Not available as an Icanpreneur tool. You can talk it through. To create a workspace you need a business description, a URL or a file.                                                    |
| Recruiting or contacting participants (outreach, LinkedIn import)                   | Not available. Create contacts for people the user gives you, create interviews, and give the user the links to share. A contact can carry a LinkedIn URL the user supplies.              |
| Creating roadmap items or engineering tickets                                       | Not available. Draft the ticket text with its evidence trail and create it only through a ticketing connector if one is present.                                                          |
| Transferring a workspace to someone else                                            | Not available. Invitations and roles are (`references/team-and-notes.md`).                                                                                                                |
| Branded interview pages                                                             | Only the research's `publicName` and respondent-facing settings can be changed (`update_research`).                                                                                       |
| Partner or revenue-share programs, pricing, plans                                   | Not tools. Point to the Icanpreneur website or support.                                                                                                                                   |
| Traction-channel strategy generation                                                | Not available. Canvas `Channel` items can be edited.                                                                                                                                      |

If a tool the user needs is absent in their client (for example a read-only connection), say which capability is missing and continue with what is possible.
