# Several workspaces

Use this for a cohort, a client portfolio or a program.

- Resolve each named workspace with `list_ideas`. If one cannot be found or opened, say so and carry on with the rest. List the inaccessible ones in the result.
- Read each workspace separately and label every finding with its workspace. Apply the same checks to each (Canvas content, research present, evidence mix, persona status) so the comparison is fair, and show the basis for any ranking or priority.
- Do not merge evidence across workspaces or attribute one startup's evidence to another. Aggregate themes only from what each workspace supports, and list the source workspaces of each theme.
- A Canvas-only request is complete from the Canvases alone. Do not require research or personas, and treat Canvas content as hypotheses. When research exists, say what is supported and what still needs testing.
- These are reads unless the user asks for changes. For a full cohort or program review, also load `icanpreneur-cohort-review`.

## Keeping clients apart (agencies and consultants)

Reuse the method across clients, never the findings. Do not use one workspace's evidence, quotes, contacts, interview content or notes in another workspace's work, even if you saw them earlier in the conversation. Reusing a script's structure or a process is fine. If a request would move content between workspaces, ask first.
